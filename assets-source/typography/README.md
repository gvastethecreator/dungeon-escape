# MEK.type fonts

The game serves these WOFF2 files from `public/assets/fonts/`.

- `mek-sans-regular.woff2`: [MEK Sans official page](https://www.mek.gallery/project/font-meksans-otf), source asset `https://framerusercontent.com/assets/ljygXKKKE3TzjJXwP9dm7v8DzA.woff2`.
- `mekzantine-regular.woff2`: [MEK.type](https://www.mek.gallery/mektype), source asset `https://framerusercontent.com/assets/t1uLVqdya4ovJmZHyUElIBz7ZE.woff2`.

The MEK Sans page describes the typeface as free to use. Mekzantine is the official alpha-test web asset. Keep these source links with any redistribution review.
